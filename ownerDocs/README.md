# ownerDocs — ownership contract

This tree is the owner's private working area, separate from the published
skill artifact at the repository root.

- Everything under `ownerDocs/` is owned and written by the **owner**
  (Mehmet), except `CLAUDE-REVIEW/`.
- `CLAUDE-REVIEW/` — Claude writes here; the owner reads.
- `CODEX-REVIEW/` — read-only for Claude. Never write here.

Subdirectories:

| Directory | Purpose |
|---|---|
| `myGeneralFiles/` | General owner notes not tied to a specific category below. |
| `myResearch/` | Research notes, working hypotheses, background reading synthesis. |
| `myManuscriptRules/` | Owner's manuscript-specific writing/formatting rules for this repo. |
| `myMethods/` | Method-development notes (derivations, protocol drafts). |
| `myProgression/` | Progress log / session-to-session continuity notes. |
| `myLiterature/` | Literature workspace: `pdfs/` (gitignored, never committed), `review/` (owner's reading notes), `manifest.json` (stub index). |
| `CLAUDE-REVIEW/` | Claude-authored review notes for the owner to read. |
| `CODEX-REVIEW/` | Codex-authored review notes. Read-only for Claude. |

This skeleton is created once, empty, and never clobbered on subsequent
scaffold passes — only missing subdirectories are added.
